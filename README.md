One word for your Wi-Fi: **Gaslighting**.

The network insists it is connected, shows full bars, and quietly loads
nothing. It is the one word every home Wi-Fi owner recognises at once —
funny because it is true, and true because it happens every day. No
explanation needed: the router is gaslighting you.

## Run it

```sh
python3 main.py
```

Writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`) and prints it. Stdlib only, deterministic — the same
word on every run. The program validates the word in code: one token, 1–20
characters, no whitespace, and verifies the written file by reading it back.
